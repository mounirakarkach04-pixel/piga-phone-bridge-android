# PIGA Phone Bridge Android

Controlled Android execution client for the PIGA Phone Bridge. Initial scope: accountless device pairing, Android Keystore P-256 identity, signed bridge requests, Ed25519 command verification, replay protection, polling, ACK/result lifecycle, and allowlisted local notification execution.

## PIGA-governed engineering workers

Codex may be used as a short-lived software-engineering capability inside the existing Pocket Enterprise five-engine workflow. It is not a sixth engine and does not receive independent device or deployment authority.

Repository-level worker rules are defined in [`AGENTS.md`](AGENTS.md). The controlled lifecycle and material-change boundaries are documented in [`CODEX_PIGA_INTEGRATION.md`](CODEX_PIGA_INTEGRATION.md).

Engineering success (`ENGINEERING_READY`) means ready for PIGA review/action admission; it never means that deployment or phone execution has been authorized.
