# Owner-Controlled Release Inputs

The engineering repository must not contain these values. They are supplied only when publication is authorized:

1. Android production signing keystore and alias.
2. Keystore and key passwords as protected GitHub repository secrets.
3. Cloudflare account authorization for the production Worker and `pigapocket.com` route.
4. Verified privacy and support contact details.
5. Google Play developer account, organization identity and payout/tax details where applicable.
6. Store asset approval, target countries, pricing and rollout decision.

All other technical work should be completed and evidenced before these owner-controlled inputs are requested.
