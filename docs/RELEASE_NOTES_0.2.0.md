# PIGA Pocket Enterprise Android 0.2.0 — Release Candidate

This candidate consolidates the Android application into one launcher dashboard, pins the production origin to `pigapocket.com`, requires explicit Master Autonomy, preserves Emergency Stop dominance and adds hardened release packaging.

The candidate also adds resolver tests, static security analysis, dependency monitoring, privacy/security documentation and a signed-or-clearly-unsigned release pipeline.

Before public distribution, the production control plane, Android signing identity, privacy/support contacts and physical-device acceptance tests must be completed by the responsible owner.
