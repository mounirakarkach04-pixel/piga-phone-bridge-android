# Product Scope — Android 0.2.0

## Included

- governed Android execution edge;
- device pairing client;
- Android Keystore identity;
- explicit Master Autonomy and Emergency Stop;
- canonical-origin pinning;
- local command allowlist;
- nonce, expiry and lease checks;
- ACK/result lifecycle and persistent result outbox;
- boot and network recovery through WorkManager;
- orchestration-plan verification evidence;
- debug and release-candidate CI pipelines.

## Not claimed by the Android repository alone

- a deployed production control plane;
- store publication or store approval;
- production signing-key ownership;
- completion of operator privacy/deletion obligations;
- unrestricted control of arbitrary Android applications;
- bypass of Android permission, security or user-confirmation boundaries;
- production authorization derived from verification alone.

The product is described as publicly market-ready only after the external production and owner-controlled gates are evidenced.
