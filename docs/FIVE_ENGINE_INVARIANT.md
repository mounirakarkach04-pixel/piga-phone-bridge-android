# Five-Engine Invariant

PIGA Pocket Enterprise contains exactly five existing engines. The Android application is a mobile execution edge. A7SEM Reverse is a binding cross-engine meta-operator used before builds and retries. Neither is counted as an additional engine.

Release automation must report:

```json
{
  "engineCount": 5,
  "additionalEngineCreated": false
}
```

Any change that creates a sixth engine or treats the Android edge as independent authority is release-blocking.
