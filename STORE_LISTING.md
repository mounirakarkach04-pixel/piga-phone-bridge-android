# Android Store Listing Draft

## App name

PIGA Pocket Enterprise

## Short description

Governed smartphone execution for capability-scoped enterprise workflows.

## Full description

PIGA Pocket Enterprise turns an Android device into a controlled execution edge for the PIGA governance architecture. Pair your device with the canonical control plane, explicitly enable Master Autonomy and allow only admitted, capability-scoped actions.

The application supports local notifications, clipboard updates, safe web intents, text-to-speech, app launching, Android share intents and verification of orchestration plans. Commands are checked for scope, nonce, expiry, lease and local safety state. Emergency Stop immediately disarms autonomous execution.

PIGA Pocket Enterprise is designed for verified results rather than simulated completion. Runtime acknowledgements and terminal receipts are preserved so interrupted network delivery does not silently repeat a local effect.

## Data safety draft

The current Android source has no advertising or behavioral analytics SDK. It processes device identity, pairing state, safety state, signed command metadata and execution receipts for app functionality and security. Final declarations must match the deployed control plane and the operator's retention and deletion policy.
